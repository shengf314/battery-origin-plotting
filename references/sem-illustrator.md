# SEM 裁剪、物理标尺与 Illustrator 工作文件

当前状态：**稳定支持**，范围限已标定的单图裁剪、标尺与原生 Illustrator AI。其余图像分析/组图不在稳定范围。

本分支将带原始标尺的 SEM 图像排成可编辑的 Illustrator 单面板：保留完整原图，采用原生矩形剪切蒙版裁剪，另建物理长度正确的白色标尺和活文字，最后由真实 Illustrator 保存 `.ai`。这是独立的显微图像流程，不进入 Origin 七个曲线图族的 registry，也不把 SEM 当作 Excel XY 曲线。原有数据曲线的视觉模板继续用于曲线；SEM 的实心标尺厚度来自本节自己的几何配置。

## 参考中观察到什么，以及采用什么

本次视觉来源是未分发的历史参考工程 的 **PDF 兼容内容，第1页 (c)/(d)/(e)**，包括图像对象、变换、标尺矢量和文字。没有为学习样式而在 Illustrator 打开参考文件。

## 每张新图的核查与标定

1. 只读检查原图及其像素尺寸、方向、单帧状态、可见标尺文字、端点和仪器信息区。当前代码只读取普通 TIFF/PNG/JPEG 的图头尺寸及方向，不宣称自动识别所有仪器页脚或完成通用标尺 OCR；由执行本技能的助手逐图查看并核实后写入请求。
2. 原始标尺的物理值和单位必须可读，端点应按该标尺实际定义量取。刻度尺通常量首尾刻度**中心间距**，不能把两端笔画的外包宽度当作物理跨度。若标尺文字、单位或端点无法确定，先完成不依赖它的清点，再集中询问这一决定性缺口。
3. `image_region_px` 记录核实过的有效微观图像区；`crop_px` 必须完全位于该区，原始仪器页脚不得进入成品。标定端点本身可以位于完整源图的页脚内。坐标采用零起点、左上原点，矩形右／下边界不包含。
4. 没有明确 ROI 时，可用 `center_crop(image_region, aspect_ratio)` 生成符合面板长宽比的**最大居中矩形**。这只是可复查的几何默认，不能称为代表性颗粒选择。需要突出某颗粒、裂纹或区域时，依据用户给出的科学意图确定 ROI，不以挑选“更好看”的形貌冒充统计代表性。
5. 保持等比缩放；X/Y比例不一致时阻塞。裁剪只改变视野，不能改变原来的每像素物理标定。DPI、软件显示百分比、倍率文字和文件名都不能单独用于长度换算。

换算关系为：

```text
pixel_span = distance(start_px, end_px)
um_per_px = original_scale_length_um / pixel_span
field_width_um = crop_width_px * um_per_px
image_scale_pt_per_px = panel_width_pt / crop_width_px
new_bar_width_pt = new_scale_length_um / um_per_px * image_scale_pt_per_px
```

新标尺的物理长度可在规划时选择便于阅读的1/2/5×10ⁿ数值，通常约占显示视野宽度的10%–25%；将最终选择明确写进 `scale_bar.length/unit`。这是规划建议，渲染器不会静默改动已写入的长度。不把历史“2 μm”或“22.709 pt”作为未来固定长度。

下方参数仅演示几何关系，不附带对应私人源图。新图必须重新核实标尺、像素跨度、有效区域及 ROI；不得照搬示例坐标或把 DPI 当物理标定。

## 显式输入与命令

从技能根目录调用，所有路径为绝对路径；`output_root` 必须独立于源图目录和技能目录。`check` 只校验来源、单位和几何，不启动 Adobe；`render` 创建、保存并重开本次自有的原生 AI。请求未知字段会报错，不通过额外字段引入去噪、增强或其他未实现处理。

```powershell
python -B -X utf8 -m plotting_core.sem_cli check --spec "D:/本次SEM任务/sem_request.json"
python -B -X utf8 -m plotting_core.sem_cli render --spec "D:/本次SEM任务/sem_request.json"
```

下面展示输入结构；路径须替换为当次文件，其标定和 ROI 坐标不可复制给别的图：

```json
{
  "schema_version": 1,
  "task_name": "sample_SEM",
  "output_root": "D:/本次SEM任务/outputs",
  "source": {"file": "D:/本次SEM原图/本次原图.tif"},
  "calibration": {
    "length": 5.0,
    "unit": "um",
    "start_px": [683.5, 843.5],
    "end_px": [1187.5, 843.5],
    "source": "本图原始5.00μm标尺及首尾刻度中心已逐像素核实；定位记录另存本次任务"
  },
  "image_region_px": [0, 0, 1280, 836],
  "crop_px": [62.5210747788492, 0, 1217.4789252211508, 836],
  "panel": {"width_pt": 163.578562, "height_pt": 118.404042},
  "scale_bar": {"length": 2.0, "unit": "um"},
  "style": {
    "bar_height_pt": 4.272,
    "bar_left_pt": 8.459119,
    "bar_bottom_pt": 6.848379,
    "label_gap_pt": 2.8,
    "scale_font": "ArialMT",
    "scale_font_size_pt": 9.3923,
    "panel_font": "ArialMT",
    "panel_font_size_pt": 12.0,
    "panel_left_pt": 9.460819,
    "panel_top_pt": 8.9,
    "bar_color_rgb": [255, 255, 255],
    "text_color_rgb": [255, 255, 255],
    "panel_label": "(a)"
  }
}
```

`calibration.source` 必须说明该图真实的标定依据，不能填“未知”。支持 `nm`、`um/µm/μm`、`mm` 的明确单位；正长度、不同且在源图内的端点、有效区域、裁剪框和面板比例均须通过校验。样式中的字体是实际 PostScript 名称；缺少指定字体时报告缺口，不静默替换。`panel_label` 可以为空字符串。颜色为0–255的RGB三元组，当前参考配置采用白色。

输出在 `output_root/task_name/attempts/<本次ID>/`：原图一致快照、请求、几何计划、真实 `.ai` 和原生回读报告。本次状态单独记录；失败不能继承此前成功。原始文件保持只读，不保存回源。

渲染另保存一份经过逐像素核对的、不带透明度的无损RGB PNG传输副本。8bit灰度只将同一灰度值复制到R/G/B，RGB样本保持原值；不裁剪、重采样、调亮或改变对比度。原始TIFF和其SHA仍独立保留，AI嵌入的是包含完整原图像素的等值传输栅格。这样规避本机Illustrator导入某些灰度TIFF时误将灰度兼作alpha的实际问题；不能靠调亮度、改PDF或覆盖图像补偿。保存后还须解码AI的PDF兼容层，核对全部RGB样本和实际alpha，不能只检查对象opacity=100%。

图头/几何校验和Adobe COM父流程兼容Python3.7；无损传输及PDF像素核对使用已有的Pillow+pypdf环境，通过独立后台worker执行。本机自动找到Codex bundled Python，也可用`SEM_IMAGE_PYTHON`指定已安装解释器，不自动安装依赖。当前像素桥接限8bit L/RGB及全不透明RGBA；16bit、透明源、多帧或未明确的灰度ICC处理会阻塞，不能隐式降位深、合成底色或转换色阶。

## Adobe 工作文件与后台执行边界

完整源图像素通过已核验的无损传输栅格嵌入 AI，原生矩形剪切蒙版隐藏 ROI 之外与仪器页脚；标尺为独立矢量，标尺文字与面板编号为可编辑活文字。保存采用 PDF-compatible Illustrator 格式，便于在不打开参考文档的情况下检查 PDF 兼容层。`.ai` 必须由真实 Illustrator 保存，不能将 PDF/SVG 或扁平图片改扩展名当作 Adobe 工作文件。

桌面 Illustrator 通过 COM/ExtendScript 创建、保存、关闭及重开本次文档。流程不调用 `activate`，不用 UI 点击，不用 Illustrator 打开参考 `.ai`；但 Illustrator 程序仍需运行，成品检查也需要把本次自有 AI 载入内存。不能把“后台脚本、不抢前台”说成“完全不打开任何文档”或真正 headless 服务。

本机 Illustrator30.8.2的温启动探针曾记录90次前台窗口样本，创建／保存／关闭期间前台未改变。这是本机证据；`Application.visible` 为只读，不能据此承诺所有启动、版本和环境均绝不显示窗口。保留当次前台观察结果，任何需要前台交互的阻塞须明确报告，不通过关闭安全提示或修改安全设置规避。

记录用户原有文档及保存状态，只关闭本次持有的文档，不退出或保存用户其他工程。临时更改的交互级别在结束时恢复；不更改首选项、安全设置、插件或字体安装。指定字体与组件不可用时保留具体缺口。

## 验收与能力边界

纯 `check` 或一张预览不能代替原生 AI 验证。正式结果至少核查：

- 源图／任务快照SHA一致；完整原图像素可从嵌入对象或PDF兼容层取得并与源图逐像素核对，不能只比较裁剪后的截图。
- 实际保存 AI 后关闭，再重开，读取画板、完整 raster、clip、标尺矩形和活文字；全部对象位置与计划相符，嵌入完整像素、X/Y等比缩放、裁剪不含页脚。
- 实测标尺几何宽度按同一标定换回物理长度，与文字值／单位一致；不能只看“2 μm”文字正确。
- 在副本实际修改剪切框、标尺或文字并保存重开，验证可编辑性；正式成品不被编辑探针修改。保存的字体、字重、颜色、图像和标尺对象身份必须回读。
- 记录用户原有文档状态与当次前台观察。视觉检查若未执行就保留未验状态，不把纯几何检查写成完整视觉通过。

当前负责单幅灰度 SEM 的明确裁剪和标尺排版，不执行EDS合成、图像分割、粒径统计、形貌定量或批量组图自动化。不得进行生成式补图、擦除／替换颗粒、滤波、锐化、对比度／亮度归一化、非等比拉伸或为匹配参考形貌而修图。遇到已处理图先记录已有处理，不据参考图推断其方法。
