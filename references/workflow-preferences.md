# 公开版默认配置与当前用户声明

本页区分可复用的视觉预设与必须由当前数据确认的科学参数。公开版不继承作者历史对话中的授权或实验身份。用户当前要求优先；已有明确声明可复用，不重复询问。

## 视觉预设

默认数据线 0.5 pt、所有文字常规体、可见主次刻度向外。循环/倍率保留 5.8 pt 全点符号，容量/倍率实心、CE 空心；GCD 不加圆点。柔和配色、字号、字体、普通画布沿用模板；轴框/刻度宽 1.0 pt、主次长 3/1.5 pt。见 [视觉配置](visual-application.md)。这些是可配置预设，不代表下载者已批准某种审美选择。

循环 CE 上置、底部配对图例及两个原生轴归属箭头可按任务启用，见 [循环布局](native-cycle-layout.md)。旧 spec 未显式启用时不迁移其行为。

## 科学参数

| 场景 | 当前数据需要的声明 |
| --- | --- |
| Na 容量换算 | 数字化学式及来源、质量基准、反应适用性、每个分支的容量参照与 Δx/绝对 x 参照；公开版不提供跨用户的科学质量基准默认值 |
| Na 放电连续性 | 样品/圈次/分支身份和实际容量起点；接充电末点须明确满足同组身份条件，不自动跨圈累积 |
| XRD 归一化 | 已扣背景且未纵移的状态与来源、method；用户明确选择 max 时使用 Y/max(Y)，不能从历史偏好推断本次背景已扣 |
| XRD 参考点 | 参考编号、物相与来源，每次任务按真实数据确定 |
| 倍率 | 真实 C-rate/Cycle 程序；阶段由连续记录决定，恢复倍率另成阶段 |
| ICP | 真实元素、单位、共同溶液/稀释基准、比例分母；不能将 ND 当 0 或默认特定五种元素 |
| GITT | 已给 D/log10 D、底数、单位、分支、参比与来源；不计算 D |

先完成不依赖缺参数的读表、字段映射、来源 hash、分组与计划，再集中询问决定结果的缺口。参数未齐时不执行相关计算；不从示例、历史工程或图像外观生成科学默认。

保留原生可编辑对象。不能可靠修复的原生导出现象应如实记录，不通过图片、矢量覆盖或修改导出物掩盖问题。每次正式绘图仍需实际图像检查。
