## 数据与阶段

`Cycle`、`Sample`、放电容量、`Rate` 为圈级字段。共享 `domains/electrochemistry/cycle_summary.py` 校验工作表、字段映射、唯一圈记录、请求范围与容量；倍率模块独立检查 C-rate，不从容量台阶推定倍率。

倍率在内存中按 Cycle 排序，源文件保持只读，并保留每条记录的原始行号。等价倍率用精确有理数规范化，例如 0.1 C 与 C/10；原始显示文本及来源仍保留。不换算未知的电流密度为 C-rate。

按相邻圈的连续 run 分段。同一倍率在高倍率之后再次出现是独立恢复阶段，不能与早期阶段合并。多样品共同绘图要求倍率值、切换圈数及阶段次序一致；不一致应拆分任务或集中确认。

## 绘图计划与验收

每个样品为一条完整放电容量系列，X=Cycle，Y=已有容量；不强行引入 CE 或双 Y。阶段标签的 X 是真实圈区间中点，文字表示对应 C-rate。marker 选择不减少线系列的原始点。

阶段文字为 Origin 原生可编辑对象，按2026-11-03规则显式常规体。默认按阶段居中并在数据正上/下方标注；`rate_labels.y_position` 为空时采用数据驱动位置，显式比例位置保持兼容，详见 [阶段标签与输入模板](rate-capability.md)。字号、画布保持，容量连线采用当前0.5pt。阶段数量来自输入，恢复阶段单独保留。

输入错误包括缺 Rate、未知/非正倍率、重复样品圈记录、缺请求范围、无缓存公式及非法容量。计划侧核对阶段覆盖、恢复阶段、原始行映射、样品程序一致性、完整点数和标签语义；Origin 侧须再保存、重开，逐系列回读绑定/点数/单位/逐点值及原生阶段文字，并检查导出图像。

无需新数据方言或通用后端中的倍率分支。registry → 独立 rate_capability ingest/plan → 共享 Origin 后端与 QA；旧科学输入兼容，视觉由当前模板及明确任务覆盖决定。
