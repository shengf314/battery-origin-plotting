# 能力状态与公开版验证边界

公开发行版本：v1.0.1，2026-11-03。引擎继承开发机上的历史 Origin 2024 / Python 3.7.1 验证；私人实验数据与历史审计未随包公开，不能将其当作下载者可复现的测试。公开 tests 和 CI 只核对离线能力，不启动 Origin。

## 绘图与简单公式

| 能力 | 实现与限制 |
| --- | --- |
| GCD | 标准长表、样品/圈次/分支、容量或已给 Na 坐标；逐圈原生 entries。未实现原生渐变色条，大量圈次图例须逐案检查 |
| 循环性能 | 原生双 Y、全部源点；可显式启用 CE 上置、下方配对图例、两个可编辑归属箭头。默认布局仅支持递增线性轴 |
| 倍率性能 | 每样品完整点线、连续阶段与恢复阶段；缺圈不补值，既有连线可能跨缺圈，需如实披露 |
| EIS | 明确实测/参考 XY；不变号、不拟合。密集近原点数据仍须实际审图 |
| GITT | 只画已给 D/log10 D；已有 log10 D 使用线性 Y。底数、单位、分支与来源必须明确 |
| XRD | 一层 XY 和离散参考 scatter；不支持 sticks/独立参考层，不扣背景或鉴相 |
| ICP | 已有比例的原生分类轴 scatter；误差棒未实现，不能忽略任务明确要求的不确定性 |
| gcd_na | CIAAW 数值化学式质量与 Faraday 容量等效坐标；不证明实测 Na 组成，绝对 x 参照不得由名义式推断 |
| xrd_normalization | max、range、range100 公式；历史端到端实机证据限 max，其他分支须单独验证。输入应已扣背景、未纵移 |
| icp_molar_ratios | 明确单位与分母；不猜 ppm/ppb、稀释或 ND。含统计的 B→A 误差棒桥接阻塞 |

XPS、dQ/dV、求导、平滑、拟合、分峰、模型反演不属于当前能力。已有 GCD/cycle/rate 输入方言保持；新 processed 输入禁止自动跳点。

## 每次运行的验收

`check` 只验证输入和计划，`doctor` 只发现环境事实。完整 `accepted` 要求 input/data/native_structure/editability/image 五项通过；失败或 dry-run 不继承旧 accepted。

保存重开须回读绑定、逐点值/顺序、单位、角色、轴变量和范围。编辑性探针在工程副本中执行，最终工程不受探针修改。必须实际查看 PNG/SVG 后记录图像审阅。反向 log10 轴的已知导出位置问题目前阻塞，不能只依靠端点回读声称支持。

深路径图片导出使用本次拥有的短 Temp 目录，按原字节复制并比较 SHA256，不编辑图像。最终 OPJU 路径过长时应缩短任务路径。不同 Origin 版本、字体与 COM 接口须按当次证据验证。

当前视觉预设见 [视觉配置](visual-application.md)。公开版删除了个人路径、私人源工程和实验工作表记录；保留的结构示例均不得当作真实数据的科学确认。
