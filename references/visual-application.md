# 视觉配置与应用边界

`templates/publication_visual_template.yaml` 是公开版视觉预设来源。默认数据曲线 0.5 pt、文字常规体、可见主次刻度向外。任务明确的 overrides 可调整支持的视觉字段；科学变量、单位、轴绑定、方向及系列边界独立确定。

| 项目 | 预设 |
| --- | --- |
| 数据线 | 0.5 pt；纯 scatter 不自动加线 |
| 文字 | 轴标题、刻度、图例、阶段标签和其他标注均常规体 |
| 符号 | 循环/倍率 5.8 pt 全点，容量/倍率实心、CE 空心；GCD 无圆点 |
| 刻度 | 可见主次刻度向外，原生 mask=10；线性轴每主间隔一个次刻度 |
| 轴框及刻度宽 | 1.0 pt |
| 刻度长度 | 主 3 pt、次 1.5 pt |
| 配色及画布 | 沿用模板中的柔和配色、字号、字体和普通画布 |

参考工程观察是历史开发依据，不是运行资源。公开包不附带私人 Origin 工程，也不要求下载者拥有作者的历史审计目录。样式预设不代表科学行业统一规范或新用户已经确认的偏好。

Origin 缺失哨兵值不能当成有效参数。参数写入成功还须保存重开回读；内部参数核对不等同完整图像验收。所有曲线、图例、轴和标注须为原生对象，不以 SVG、outlined text、图片或其他覆盖层替代。旧 overlay 辅助模块不进入正式 pipeline。
